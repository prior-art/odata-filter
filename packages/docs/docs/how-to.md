# Examples

Browse the examples below to see how to use the OData Filter library in common scenarios.

## Desktop playground

The Electron playground packages the parser and schema validator into a desktop interface for
learning OData grammar and assembling filters with buttons. Run it from a source checkout with:

```sh
npm run dev --workspace=packages/playground
```
